# בודק זכויות יוצרים

כלי לסריקת תמונות ומציאת מידע על זכויות יוצרים אוטומטית.

## שימוש
פתח את הכתובת: https://guydi.github.io/copyright-tool/

1. לחץ "בחר תיקייה" ובחר את תיקיית התמונות שלך
2. בחר את הארכיונים לחיפוש
3. לחץ "חפש זכויות יוצרים"
4. עבור את הסיכום ובצע עריכות בחלון הריוויו אם צריך
5. הורד את קובץ ה-CSV וייבא אותו ל-Monday.com

## ארכיונים נתמכים
- Wikimedia Commons
- Library of Congress
- Pexels
- Shutterstock (זיהוי לפי שם קובץ)
